# Ashley — Learn, Play & Wonder

Ashley's first mobile-friendly educational companion prototype for children aged 4 and 6.

## Current starter version
- Play Mode (age 4) and Explorer Mode (age 6)
- English, Bahasa Melayu and Chinese prompts
- Starter activities: counting, animals, stories, puzzles, maths and words
- Responsive design for phones and computers
- No accounts, analytics, storage, or API keys

## Publish from your Android phone
1. Open this repository on GitHub.
2. Tap **Add file → Upload files**.
3. Upload `index.html` from this ZIP and commit it to the `main` branch.
4. Open **Settings → Pages**.
5. Under Build and deployment, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
6. After GitHub Pages finishes building, the page will be available at `https://lyonleong-glitch.github.io/Ashley-kids-ai/`.

## Important limitations
This is a front-end demo with scripted replies, not a connected AI assistant yet. Do not enter children's names, personal details, or sensitive information. Before connecting an AI API, use a secure server-side endpoint; never put an API key in browser code or commit it to GitHub.
